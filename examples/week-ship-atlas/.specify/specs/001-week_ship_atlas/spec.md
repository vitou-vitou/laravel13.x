# Feature Specification: Week Ship Atlas

**Feature Branch**: `001-week_ship_atlas`  
**Created**: 2026-08-05  
**Status**: Implemented (MVP)

## User Scenarios & Testing

### P1 — Week board
As a learner, I open `/` and see Mon–Sun columns with my ship notes so I can track the week loop.

### P1 — Create note
As a learner, I create a note with region, company habit, project type, practice, and verdict.

### P1 — Edit / delete
As a learner, I edit or delete a note from the board.

## Functional Requirements

- FR-001: Home shows 7 weekday panels
- FR-002: CRUD for `ship_notes`
- FR-003: Seed Week 1 starter notes
- FR-004: Feature tests cover board + store + validation

## Out of Scope (MVP)

- Auth, multi-tenant, publish-to-blog API, Canvas embed
