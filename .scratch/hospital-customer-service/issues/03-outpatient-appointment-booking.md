# 03: Outpatient Appointment Booking & Staff Review

**What to build:** An online outpatient appointment request flow where patients request visit slots for specific hospital specialties or doctors, and hospital coordination staff review, confirm, or propose rescheduled times.

**Blocked by:** 01: Hospital Foundation & Guest FAQ Decision Tree

**Status:** done

- [x] Patient can submit an appointment booking request by selecting department, preferred doctor (optional), date, preferred time slot (morning/afternoon), and entering patient name and contact details.
- [x] Patient receives an appointment tracking code to verify their request status at any time.
- [x] Staff appointments desk can view all incoming booking requests filtered by department and status (Pending, Confirmed, Rescheduled, Cancelled).
- [x] Staff can confirm an appointment with specific counter/room instructions or suggest an alternate time slot.
- [x] Patient can view the updated confirmation details using their tracking code or phone number.
