# 10: Attachments

**What to build:** Raisers can attach up to 3 images or PDFs (max 5MB each) when they submit, and Agents can view and remove them.

**Blocked by:** 01, 03

**Status:** ready-for-agent

- [ ] The public form accepts up to 3 images or PDFs of max 5MB each, and rejects others with errors
- [ ] Files are stored privately and only staff can view them
- [ ] An Agent can remove an Attachment, for example a medical document under ADR 0001
- [ ] Feature tests use a storage fake
