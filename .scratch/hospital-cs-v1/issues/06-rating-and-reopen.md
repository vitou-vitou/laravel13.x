# 06: Rating and Reopen

**What to build:** When a Case is Resolved, the Raiser can rate it 1-5 on the Status check page, or press not satisfied to Reopen it.

**Blocked by:** 02, 04

**Status:** ready-for-agent

- [ ] Rating is only offered when the Case is Resolved, and is stored as 1-5
- [ ] Not satisfied moves the Case from Resolved back to In progress
- [ ] Rating or Reopen requires a valid Reference and phone pair
- [ ] Nothing is offered for a Closed Case
- [ ] Feature tests through public HTTP
