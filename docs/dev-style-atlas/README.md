# Dev Style Atlas

**Purpose:** Learn worldwide software working styles day by day, clear yourself first, then post what you practiced.

**Honest model (read this first):**
- **Countries** = covered via **all world regions** (every country sits in a region).
- **Companies** = covered via **archetypes + flagship examples**. You classify any new company into an archetype — you do not memorize millions of logos.
- **Project types** = full software **family catalog** (each family has concrete subtypes).
- Blog value formula: **Region × Company habit × Project type + practice evidence**.

Open the live browser beside chat: Cursor canvas `dev-style-atlas`.

**Laravel demo app:** `examples/week-ship-atlas` — 7-day ship board (CRUD notes).

---

## How to clear yourself (before posting)

Answer these once per week:

1. What am I optimizing for this week — speed, craft, security, or regulated quality?
2. Which region style am I borrowing?
3. Which company archetype habit will I steal (one only)?
4. Which project type am I practicing on?
5. What is out of scope this week?

If you cannot answer in 5 lines, do not post yet — clear with a partner (or this chat) first.

---

## Week loop (post every Friday)

| Day | Focus | Do |
|-----|--------|-----|
| Mon | Region | Pick 1 region. Note 3 steal habits + 1 skip trap. Draft 8 lines. |
| Tue | Company | Pick 1 archetype + 2 flagships. Map 1 habit to your current project. |
| Wed | Project type | Write goal, risks, must-have slices, out-of-scope. |
| Thu | Practice | Apply 1 habit in real code (1–2 hours). Capture before/after. |
| Fri | Publish | Ship post: Region × Habit × Project type + what you tried. |
| Sat | Compare | Contrast 2 regions or 2 companies on same project type. |
| Sun | Clear | Keep / drop / next week theme. |

### Friday post template

```text
Title: [Region] × [Company habit] × [Project type]

1. What they optimize for
2. What they sacrifice
3. One habit I stole this week
4. Where I applied it (path / screenshot)
5. Keep or drop?
```
