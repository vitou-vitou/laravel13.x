Auto Endorsement — Full User Journey

Product: Auto · Module: Endorsement
URLs: /endorsements/auto · edit /endorsements/auto/:id/edit · detail /endorsements/auto/:id
Generate from: approved Auto policy → Generate Endorsement

1. Journey overview

[APV Policy]
    │ Generate Endorsement (type + e-date + desc)
    ▼
[PND · approved_status usually PRG]
    │ Edit: Info / Vehicles / Deductible / Config / Commission / Reinsurance
    │ (± Cancellation / Endorsement Info by type)
    │
    ├─ Incomplete RI → Submit disabled · forced PRG
    ├─ RI complete → Submit enabled
    │
    │ Submit (SBM)
    ▼
[PND · SBM]
    │ Detail Approve button ONLY if:
    │   · ENDORSEMENT.APPROVE permission
    │   · RI complete
    │   · business_type + policy_type complete
    │   · status=PND AND approved_status=SBM
    │
    ├─ Approve (APV) → invoice/CDN/QR if premium ≠ 0 → print / next generate
    ├─ Reject  (REJ) → revise → PND → edit again
    └─ Delete (cancel SP) if not APV

3. Approve / Reject gate

Button shows only when all are true:

#GateWhereTable / column
1Permission ENDORSEMENT.APPROVEFE—
2Reinsurance completeFE + BEins_reinsurance_data: Σ share = 1 per detail_id for stage
3Config completeFE + BEins_policy.business_type AND policy_type set
4PendingFEins_policy.status = PND
5SubmittedFEins_policy.approved_status = SBM
Reject writes: ins_policy.status → REJ, approved_reason, approved_at, approved_by. Column approved_status stays SBM. FE payload key approved_status: "REJ" maps to column status.

5. Sequence — full path + reject

sequenceDiagram
    autonumber
    actor User
    participant Pol as Policy Detail APV
    participant Gen as generate-auto-endorsement
    participant SP as gen_new_policy_endorsement SP
    participant Edit as Endorsement Form
    participant PolT as ins_policy
    participant AutoT as auto master/detail
    participant RI as ins_reinsurance_data
    participant Det as Endorsement Detail
    participant Apv as POST endorse approve

    User->>Pol: Generate Endorsement
    Pol->>Gen: policy_id + type + dates
    Gen->>SP: create endt row
    SP->>PolT: INSERT status=PND
    SP->>AutoT: clone master + details
    Gen-->>User: open edit form

    User->>Edit: Config business_type / policy_type
    Edit->>PolT: UPDATE config cols
    User->>Edit: Vehicles / Commission / RI
    Edit->>RI: shares per detail_id
    Note over RI: complete when sum share = 1

    alt RI incomplete
        Edit->>PolT: approved_status = PRG
        Note over Edit: Submit disabled
    else RI complete
        User->>Edit: Submit
        Edit->>PolT: approved_status = SBM
    end

    User->>Det: Open detail
    User->>Det: Approval → Reject + remark
    Det->>Apv: approved_status REJ
    Apv->>RI: isReinsuranceCompleted?
    Apv->>PolT: business_type and policy_type set?
    alt gate fail
        Apv-->>Det: Endorsement data has not completed
    else gate ok
        Apv->>PolT: status=REJ + reason + audit
        Note over PolT: approved_status stays SBM
        Apv-->>Det: Rejected successfully
    end

    end

8. Verify SQL

-- Endorsement row
SELECT id, document_no, data_id, status, approved_status,
       business_type, policy_type, approved_reason, approved_at, approved_by
FROM ins_policy
WHERE id = :endt_id;

-- Config gate
SELECT (business_type IS NOT NULL AND policy_type IS NOT NULL) AS config_ok
FROM ins_policy WHERE id = :endt_id;

-- RI gate
SELECT detail_id, SUM(share) AS total_share
FROM ins_reinsurance_data
WHERE policy_id = :endt_id
  AND endorsement_stage = :document_no
GROUP BY detail_id;
