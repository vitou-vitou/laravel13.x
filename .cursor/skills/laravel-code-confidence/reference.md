# Code confidence — reference

## Full 5-point ladder (phase boundary only)

1. **Trace shape** — pack cites docs/starter/`vendor`/neighbor file.
2. **Thin layers** — pack’s thin shape only.
3. **Pin versions** — language lockfiles for that stack.
4. **Behaviour test** — one red/green for moved behaviour.
5. **Fixed-point review** — diff vs pack + this repo’s dialect.

## Daily vs dial-up

| | Daily | Dial up |
|---|---|---|
| Lockfiles | trust | still trust |
| Layers | keep thin | justify new seam |
| Primary source | skip | required for new patterns |
| Public contracts | match neighbors | treat as API |
| Review | skip | one pass on diff |

## Patch discipline

| Do | Don’t |
|---|---|
| One pack per stack | Mega-SKILL with every framework |
| Detect row in `_registry.md` | Rely on chat memory |
| Short packs + doc links | Paste long tutorials into packs |
| Sync personal ↔ repo mirrors when you care | Assume Cursor learns from sessions |
| Mode D after **two** repeats of same lesson | Patch on every one-off |

Research dumps (`/research`) are inputs to Mode D — they do not replace a pack.

## Common false confidence

| Belief | Reality |
|---|---|
| “AI used the right buzzwords” | Still app code |
| “Works on my other stack” | Wrong pack — re-detect |
| “Filament/Keycloakify/Inertia = Laravel core” | Separate first-parties; check pack |
| “Monorepo root patterns apply to every package” | Per-package dialect |
| “Skill will remember this chat” | Patch Mode D or it is gone |
| “UI packs = all of Laravel” | Dialect only. Engine → docs for locked major. Admin years → `stacks/admin-5y-roadmap.md` |
