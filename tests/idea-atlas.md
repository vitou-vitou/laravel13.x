# Idea Atlas — Treasure Map of Money Projects

> A living map. Ideas = buried treasure. You = explorer. Each project is a dig site with a riddle (Khmer *kamnap* hint), a distribution map, and loot type. Import `idea-atlas.csv` as a Notion database, then set its view to **Board** (group by `Zone`) or **Timeline** (by `Time to Gold`).

## How to read the map

- **Zone** — category of treasure (Micro-SaaS, API, Extension, AI Agent, Digital Product).
- **Status** — your journey stage:
  - `Scouting` — still reading the map, not committed.
  - `Buried` — chosen, waiting to dig.
  - `Digging` — building now.
  - `Gold` — shipped, earning.
- **Time to Gold** — estimate from dig to first dollar.
- **Loot Type** — Recurring (subscription), Usage (pay-per-call), One-time.
- **Dig Effort** — 1 (weekend) → 5 (moon-shot).
- **Map (Distribution)** — where the buyers already gather. *This is the real treasure — code is just the shovel.*
- **Riddle** — a *kamnap*-style hint naming the hidden pain the treasure solves.

## The Explorer's Rule

> Distribution is the treasure, not the code. Only dig where you can already reach the crowd.

Pick **one** dig site. Move it to `Digging`. Ship in the `Time to Gold` window. Everything else stays `Scouting` — no digging two holes at once.

## Legend of Riddles (Kamnap)

Each treasure carries a riddle naming the pain it buries. Read it aloud before you dig — if the riddle doesn't move you, the treasure isn't yours.
