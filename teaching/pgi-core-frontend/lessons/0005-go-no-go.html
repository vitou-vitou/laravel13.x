Lead decisions without writing code — a tree you can run in the meeting

Lesson 5 • 6 min • Prerequisites: L3, L4

Decision Tree

Is sale: live in direct-book-lines.json?
  NO  → Do not demo create-quote. Label WIP.
  YES → Did UAT smoke pass L1+L2+L3 PDF?
         NO  → NO-GO. Block merge to UAT/prod.
         YES → Did php artisan test + analyse pass on the branch?
                NO  → NO-GO until green.
                YES → GO for that product cell set.

Hard NO-GO (Never Negotiate)

SignalWhy
PDF blank / missing sections Customer cannot sign / bind
Save throws surprise error Staff cannot complete journey
403 after login on known menu item Permission map broken — not "UI polish"
Works in npm run dev only Production CSS / build trap
Touching legacy 0121–0125 "while we're here" Out of Direct Book scope; high blast radius

Soft HOLD (Ship Later, Not Never)

  • Copy / label wording imperfect but PDF complete
  • WIP product not yet live (expected)
  • PAI slow but succeeds under 60s timeout
